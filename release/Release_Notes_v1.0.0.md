# 极维工具箱 v1.0.0
Windows 系统运维工具箱 | Tauri 2 + Vue 3

支持批量软件安装、Geek 风格深度卸载、软件备份还原、硬件检测与系统工具，面向装机、二手验机、系统重装运维场景。

## 新增功能

- 批量安装：内置 26 款软件清单，支持远程更新与依赖校验；串行队列支持暂停/继续/终止/失败重试/清理，下载带断点续传、SHA256 校验与限速
- 任务模板：保存软件组合与静默参数，支持标签、复制、导出 Markdown 装机清单
- 快速工作台：本机概况、模板快捷入口、高频工具、垃圾概览、最近任务
- 深度卸载：Geek 式流程、残留扫描、占用文件登记重启删除，黑白名单防止误删系统目录
- 软件备份还原：`.jwbak` 内含 manifest 校验，支持跳过/覆盖/重命名三种冲突策略
- 硬件检测：六栏视图，CPU 烤机带超温自动终止，磁盘测速与 SMART 计数，屏幕坏点检测
- 系统工具：运行库、驱动、启动项与服务、Hosts、垃圾清理、环境变量与 Path 条目、登录计划任务
- 系统监控与磁盘空间：实时折线、进程表、目录用量、大文件扫描
- 快捷工具：端口查询、系统入口白名单、定时关机、快捷命令、失效快捷方式清理、系统信息导出
- 日志中心支持筛选、搜索与打包导出；代理设置真正作用于全部下载链路

## UI 优化

- 全套紫色渐变换装：exe 资源、任务栏托盘、各尺寸 PNG 统一
- 标题栏、安装向导、关于页统一 AppMark 品牌图形
- 侧栏分组与工作台工具卡统一色标，空状态改用矢量图
- 深浅主题、权限提示条、切页动画与进度扫光

## 修复

- 压测缺少超温保护，可能过热
- 开机时间单位错误（毫秒当秒）
- 代理配置写了却不生效
- 软件库搜索范围过窄
- 依赖关系从未真正生效
- 非空目录删除误报成功
- CPU 首次采样假报 100%、进程数恒为 0
- 单元素 JSON 序列化退化导致解析失败

## 使用须知

1. 推荐以管理员权限运行，解锁深度卸载、服务与注册表等系统级功能
2. 深度卸载与注册表操作存在风险，操作前请创建系统还原点或备份
3. 加密备份包密码遗失后无法恢复
4. 本工具仅作系统辅助用途，操作风险由使用者自行承担

## 已知限制

- 部分硬件字段依赖 WMI/CIM 提供方，虚拟机与精简系统上可能为空
- GPU 烤机与部分传感器读数取决于驱动与主板支持
- 便携版不跨机器保存配置
