# 极维工具箱 产品规格文档

- 版本：v1.0（重建版）
- 日期：2026-10-17
- 适用平台：Windows 10 / 11 x64
- 技术形态：桌面应用（Tauri + WebView2 前端）
- 文档约定：【P0】= 首版必须；【P1】= 次优先；【P2】= 增强。验收标准以 AC-x 编号。

---

## 0. 全局架构约定

### 0.1 四目录分离

| 用途 | 路径 | 说明 |
| --- | --- | --- |
| 程序本体 | `{pf}\极维工具箱` | Program Files 下，只读，UAC 控制写入 |
| 用户配置 | `Documents\极维工具箱\配置` | settings.json、dirs.json、白名单等 |
| 备份导出 | `Documents\极维工具箱\备份导出` | .jwbak 文件默认落盘位置 |
| 缓存 | `LocalAppData\极维工具箱\缓存` | logs/、下载临时文件、缩略图缓存等 |

- `dirs.json` 必须以 **utf-8-sig** 解析（容忍 BOM），解析失败时回退到默认目录表并告警。
- 所有路径可被配置覆盖；程序启动时校验目录可写性，不可写则降级为只读模式并提示。
- 日志目录固定为 `{缓存}\logs\`，备份临时目录固定为 `{缓存}\backup_tmp\`。

**验收标准**
- AC-0.1：修改 dirs.json（含 BOM 文件）后重启，四个目录全部按新配置生效。
- AC-0.2：配置目录被删除时，程序能自动重建默认目录结构并继续运行。
- AC-0.3：缓存目录不可写时（模拟 ACL），功能降级、给出明确提示、不崩溃。

### 0.2 通用横幅与权限

- **UAC 权限横幅**：启动后检测是否管理员；非管理员时顶部显示常驻横幅"当前未以管理员身份运行，部分功能（系统工具/深度卸载/烤机）受限"，提供"以管理员重启"按钮（ShellExecute runas 自身）。
- **WebView2 运行时横幅**：检测 WebView2 Runtime 是否存在；缺失时显示横幅并提供官方安装包下载/运行检测。
- **托盘**：最小化到托盘；右键菜单（显示主窗/退出）；点击托盘图标恢复窗口。
- **退出确认**：托盘"退出"或关闭按钮弹出确认框（可勾选"不再提醒"，存 settings.json）。
- **开机自启**：注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，键名 `JiWeiToolbox`，值为主程序路径；设置页开关式控制。

**验收标准**
- AC-0.4：非管理员运行可见横幅，点击后触发 UAC 弹窗并以管理员身份重启。
- AC-0.5：卸载 WebView2 后启动仅出现横幅，主体不崩溃；安装后横幅消失。
- AC-0.6：开机自启开关写入/删除注册表值，重启系统后行为一致。

### 0.3 配置与缓存管理

- **配置导入导出**：配置导出为 JSON（settings、dirs、软件勾选偏好、白名单）；导入时做 schema 校验 + 版本号迁移，非法字段拒绝并提示。
- **缓存管理**：统计缓存总大小与分项（logs / 下载 / backup_tmp）；一键清理；清理前二次确认。

**验收标准**
- AC-0.7：导出 → 修改 → 导入往返，配置无损；损坏的 JSON 导入被拒绝且不污染现有配置。
- AC-0.8：缓存大小统计与磁盘实际占用误差 < 5%；清理后统计归零、程序仍正常运行。

### 0.4 文件日志中心

- 缓存目录 `logs/` 下按日分文件：`jw-YYYYMMDD.log`，UTF-8，按行追加。
- 日志级别：DEBUG / INFO / WARN / ERROR；每条含时间戳、模块、级别、消息。
- 界面提供：按日期选文件、按级别/关键字筛选、查看详情、导出单日或合并导出（zip）。
- 自动清理：默认保留最近 30 天，可配置；超期文件启动时清理。

**验收标准**
- AC-0.9：跨日运行产生新文件且内容互不混杂；日志为合法 UTF-8。
- AC-0.10：界面筛选（级别+关键字组合）结果与文件内容一致；导出文件可打开。
- AC-0.11：把系统日期回拨/前推，保留策略按文件名日期正确清理。

## 1. 批量安装

### 1.1 功能点

1. **内嵌软件清单**：程序内置 `resources/softwares.json`（见该文件 schema）。启动时加载，作为基线数据。
2. **远程更新**：从配置的远程 URL（settings.json 中 `softwareListUrl`）拉取最新清单；比对 `version` 字段（或内容哈希）后覆盖本地缓存；拉取失败时静默使用内嵌清单并记日志。远程清单同样按 utf-8-sig 容错解析。
3. **串行下载队列**：用户勾选多个软件后进入队列，**同一时刻仅一个下载任务**；队列展示当前项进度、速度、剩余时间；支持暂停/继续/取消单任务与清空队列。
4. **断点续传**：下载使用 HTTP Range（`Range: bytes=<received>-`），服务端返回 206 则续传，返回 200 则重下；未完成文件存 `{缓存}\download\{id}.part`，完成后重命名为正式文件。
5. **SHA256 校验**：清单项 `sha256` 非空时，下载完成后计算哈希比对；不匹配 → 删除文件、标记失败、记 ERROR 日志。为空时跳过校验并在 UI 上标注"未校验"。
6. **静默安装参数库**：每个软件带 `silentArgs` 模板，支持变量 `{file}`（安装包路径）、`{lang}`（系统语言）。按 `type` 区分执行方式：`exe`（直接运行）、`msi`（msiexec /i ...）。
7. **安装失败重试**：安装器退出码非 0（或 3010 视为成功需重启）时自动重试，默认 2 次、间隔 5s；重试仍失败 → 标记失败、写日志、继续队列下一项；结果面板汇总成功/失败/需重启。

### 1.2 交互流程

```
选择软件(分类/搜索/全选) → [开始下载安装]
  → 队列循环：
     下载(断点续传) → SHA256校验 → 静默安装(silentArgs) → 退出码判定
       ├─ 成功/3010 → 下一个
       └─ 失败 → 重试×2 → 仍失败 → 标记失败 → 下一个
  → 结果汇总面板（成功/失败/需重启，失败项可单独重试）
```

### 1.3 验收标准

- AC-1.1：勾选 3 个软件串行执行，任意时刻系统内只有 1 个下载连接（可用抓包/任务管理器验证）。
- AC-1.2：下载到 50% 时暂停程序重启，点击继续后从 50% 附近续传（服务端支持 Range 时流量≈剩余一半）。
- AC-1.3：篡改清单 sha256 后安装被拦截，文件被清理，日志含 ERROR 记录。
- AC-1.4：模拟安装器返回 1602（用户取消），触发 2 次重试后进入失败列表。
- AC-1.5：远程清单地址不可达时使用内嵌清单，功能不受影响且日志有 WARN。
- AC-1.6：退出码 3010 归类为"成功（需重启）"而非失败。

## 2. 深度卸载

### 2.1 功能点

1. **已安装软件枚举**：
   - 传统程序：遍历 `HKLM\...\Uninstall`（含 Wow6432Node）、`HKCU\...\Uninstall`，读取 DisplayName / DisplayVersion / UninstallString / InstallLocation / EstimatedSize / SystemComponent。
   - UWP：`Get-AppxPackage`（PowerShell）获取 Name / PackageFullName / InstallLocation。
   - 合并去重（同名同版本合并），标注来源（HKLM/HKCU/UWP）。
2. **残留扫描**：卸载完成后（或对任意已卸载名称手动触发），按关键字匹配扫描：
   - 目录：`Program Files`、`Program Files (x86)`、`ProgramData`、`%LocalAppData%`、`%AppData%`
   - 注册表：`HKLM\Software`、`HKCU\Software` 下同名键
   - 命中项以列表展示（路径/类型/大小），**必须经用户勾选确认后**才删除，误报白名单可勾选"不再扫描此项"。
3. **一键清理**：对选中残留项执行删除；文件删除失败（占用）→ 记日志并列入"待重启删除"（MoveFileEx MOVEFILE_DELAY_UNTIL_REBOOT）。
4. **UWP 应用移除**：对 UWP 项执行 `Remove-AppxPackage`；提供"仅当前用户/所有用户"选项。

### 2.2 交互流程

```
打开深度卸载 → 扫描已安装列表(传统+UWP) → 搜索/过滤 → 选中程序
  → [卸载] → 运行官方卸载器(等待退出) → 自动残留扫描 → 勾选残留 → [清理选中]
```

### 2.3 验收标准

- AC-2.1：枚举结果与"系统设置-应用"列表数量级一致，UWP 应用出现在列表且可移除。
- AC-2.2：卸载一个测试程序后，残留扫描能发现其 ProgramData 与 AppData 目录。
- AC-2.3：清理被占用的文件不崩溃，进入待重启删除计划。
- AC-2.4：SystemComponent=1 / Windows 补丁默认不展示（可在设置中开启"显示系统组件"）。
- AC-2.5：UWP 移除后 Get-AppxPackage 查询不到该包。

## 3. 硬件检测

### 3.1 功能点

1. **sysinfo 总览**：CPU（型号/核心/线程/当前频率）、内存（容量/条数/频率）、主板（厂商/型号）、BIOS（版本/日期）、显卡（型号/驱动版本/显存）、网卡（名称/MAC/IP）、磁盘列表（型号/容量/接口/分区）。数据源 WMI（root\cimv2）+ Win32 API；支持一键复制报告（文本）。
2. **CPU 烤机**：多线程负载（Avx/浮点+整数混合运算），可选线程数、时长；实时显示各核心占用与温度（可获取时）、结束后展示稳定时长/最大频率。
3. **GPU 烤机**：基于 wgpu 的计算 shader 满载压力；显示 FPS（渲染帧循环）/利用率；可选时长；异常（设备丢失）时安全停止并提示。
4. **内存测试**：分配大块内存做读写校验（多轮 pattern 写入-读出比对），报告进度与错误地址；可测容量可配置（默认物理内存的 50%）。
5. **磁盘健康与测速**：
   - SMART：通过 WMSmart/Storage Reliability Counter（WMI MSStorageDriver_FailurePredictData 或 `Get-PhysicalDisk` ReliabilityCounter）读取温度/通电时间/重映射扇区等，给出健康状态（良好/警告/未知）。
   - 测速：顺序读/写（1MB 块，测试文件默认 1GB 于所选分区，测后删除），显示 MB/s。
6. **屏幕坏点检测**：纯色全屏轮播（红/绿/蓝/白/黑），点击或按键切换颜色，Esc 退出；提示用户肉眼观察。

### 3.2 交互流程

- sysinfo：进入页面自动加载 → "刷新/复制报告"。
- 压力测试类：参数设置 → 开始 → 实时曲线/数值 → 停止或倒计时结束 → 结果摘要。烤机进行中关闭页面须先确认停止。
- 磁盘：选磁盘 → 看健康 → 选分区 → 测速（进度条）。
- 坏点检测：开始 → 全屏色块轮播 → Esc 退出。

### 3.3 验收标准

- AC-3.1：sysinfo 各字段与任务管理器/设备管理器/msinfo32 一致（允许格式差异）。
- AC-3.2：CPU 烤机期间所有线程 100%（任务管理器验证），停止后 1s 内降载。
- AC-3.3：GPU 烤机期间 GPU 利用率显著升高（任务管理器 GPU 页验证）；拔掉显示器等异常不导致应用崩溃。
- AC-3.4：内存测试人为注入坏 pattern 时能报告错误轮次与偏移。
- AC-3.5：磁盘健康：对支持 SMART 的盘显示非"未知"状态；测速文件测后删除、不残留。
- AC-3.6：坏点检测覆盖全屏（含任务栏），Esc 必定退出。

## 4. 系统工具

### 4.1 功能点

1. **运行库检测安装**：检测 VC++ 2005–2022（x86/x64，读注册表 Uninstall 键或 `MsiGetProductInfo`）与 DirectX（检测 d3dx9_*.dll / xinput 存在性）；缺失项列表勾选后下载安装（复用批量安装的下载/校验能力）。
2. **驱动列表**：枚举设备（SetupAPI/WMI Win32_PnPSignedDriver）：名称/版本/日期/厂商/问题状态；支持导出 CSV；提供"打开设备管理器"入口（不直接装卸驱动，避免风险）。
3. **启动项管理**：聚合三类来源并列出，支持启用/禁用/删除：
   - 注册表 Run/RunOnce（HKLM、HKCU、Wow6432Node）
   - 启动文件夹（用户与公共：`%AppData%\...\Start Menu\Programs\Startup` 与 ProgramData 对应目录）
   - 计划任务（Task Scheduler 中触发器为"登录时"的任务，只读展示+禁用入口）
4. **服务管理**：枚举 Win32_Service（名称/显示名/状态/启动类型），支持 启动/停止/禁用/自动/手动；对关键系统服务（csrss、winlogon 等黑名单）禁止操作；修改需二次确认。
5. **Hosts 编辑**：加载 `C:\Windows\System32\drivers\etc\hosts`（utf-8 容错解析），文本编辑 + 行级启用/禁用（# 注释切换）；保存前自动备份到缓存目录（hosts.jw-YYYYMMDD.bak）；保存后 `ipconfig /flushdns`。
6. **垃圾清理**：分项统计大小并勾选清理：
   - 用户/系统临时文件（%TEMP%、%WINDIR%\Temp）
   - 回收站（各盘）
   - 缩略图缓存（`%LocalAppData%\Microsoft\Windows\Explorer\thumbcache_*.db`，先停止 Explorer 对应占用或跳过占用文件）
   - 浏览器缓存（Chrome/Edge/Firefox 的 Cache 目录；进程运行中的项标记"需关闭浏览器"）
7. **环境变量编辑**：分别列出用户（HKCU\Environment）与系统（HKLM\...\Session Manager\Environment）变量；增/删/改；Path 提供条目化编辑（拆分 `;`）；保存后广播 `WM_SETTINGCHANGE`。

### 4.2 验收标准

- AC-4.1：卸载一个 VC++ 运行库后，检测列表正确显示缺失并可安装补齐。
- AC-4.2：启动项禁用后（改名/删除前备份到缓存），重启登录验证该项不再自启；可从备份恢复。
- AC-4.3：对系统关键服务的操作被拒绝并提示原因。
- AC-4.4：Hosts 保存后内容正确、备份文件存在、DNS 缓存已刷新。
- AC-4.5：垃圾清理后各分项大小归零（浏览器缓存除外，运行中浏览器项被正确标记）。
- AC-4.6：环境变量修改后新开 cmd（父进程经 Explorer 刷新）可见新值；Path 编辑不破坏原有条目。

## 5. 软件备份

### 5.1 功能点

1. **配置目录备份**：内置常见软件配置路径表（如 Notepad++、Everything、PotPlayer、VSCode 的 settings、Snipaste 等）；用户勾选要备份的软件；按目录打包。
2. **备份导出 .jwbak**：格式为 zip（扩展名 .jwbak），内部结构：
   ```
   manifest.json      # 版本、时间、来源机器、文件清单+每文件 SHA256
   files/...          # 原始目录结构
   ```
   默认保存到 `Documents\极维工具箱\备份导出\{名称}-{时间戳}.jwbak`。
3. **恢复**：选择 .jwbak → 校验 manifest 与文件哈希 → 冲突策略（跳过/覆盖/重命名）→ 按 manifest 还原到原路径（目标路径不存在则创建）。

### 5.2 验收标准

- AC-5.1：备份-恢复往返后文件内容逐一一致（哈希校验通过）。
- AC-5.2：.jwbak 用任意 zip 工具可打开，manifest.json 合法且与文件清单一致。
- AC-5.3：恢复时选择"覆盖"，旧文件被替换；选择"跳过"，旧文件保留且日志记录跳过数。
- AC-5.4：损坏的 .jwbak（篡改文件内容）恢复时哈希校验失败并中止，不产生半还原状态（先校验后解压落盘）。

## 6. 非功能需求

| 项 | 要求 |
| --- | --- |
| 安全 | 所有下载强制 HTTPS；哈希校验；删除类操作必须二次确认；不做静默提权 |
| 性能 | 主界面冷启动 < 3s；软件枚举 < 5s（500 台程序规模）；UI 不因下载/烤机卡顿 |
| 稳定性 | 任何子任务失败不得导致主进程退出；全部异常落日志 |
| 隐私 | 不上传任何用户数据；远程更新仅拉取清单文件 |
| 兼容 | Win10 1903+ / Win11；WebView2 Evergreen；高 DPI 适配 |
| 日志 | 全模块接入日志中心（§0.4） |
