## 技术风险与前置验证（建议 M1 期间并行 spike）

1. **断点续传**：确认目标下载源均支持 Range（部分国内 CDN 不支持 206）——影响 1.4 设计。
2. **GPU 烤机**：wgpu 在目标用户显卡（老款 Intel 核显）上的兼容性——影响 3.4。
3. **SMART 读取**：无管理员权限时的降级策略；NVMe 与 SATA 的数据源差异——影响 3.6。
4. **静默安装参数**：社交办公类（微信/QQ/钉钉/飞书）安装器静默参数需逐一实测验证——影响 1.6 与清单 silentArgs 字段。
5. **UWP 枚举性能**：PowerShell 进程冷启动耗时，必要时改用 WinRT 直接调用——影响 2.2。
