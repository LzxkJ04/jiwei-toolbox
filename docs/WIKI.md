# Wiki 文档结构

GitHub Wiki 面向使用者，与 `docs/` 下面向维护者的文档分工：

- `docs/`：需求文档、发布流程、版本归档，偏内部
- Wiki：安装、使用、排障，偏外部读者

## 首页 Home

- 一句话定位与适用人群
- 三分钟上手：下载 → 安装 → 首次运行
- 功能总览表（六板块 + 一句话说明 + 跳转链接）
- 系统要求：Windows 10 1809 及以上 / Windows 11，x64；WebView2 Runtime
- 下载入口指向 Releases

## 1. 安装与卸载

- 安装版流程：安装向导 7 页说明、路径选择、组件选择、依赖预检

- 无人值守部署：`unattend.json` 字段说明、退出码 0/1/2
- 修复模式 `--repair` 能修复什么、不能修复什么
- 卸载：保留用户数据的默认行为、彻底清理的方法
- 静默安装参数表
