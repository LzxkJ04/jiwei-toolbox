## 要点摘录

新增：批量安装与依赖校验、任务模板、快速工作台、深度卸载与黑白名单、备份清单校验与冲突策略、硬件检测六栏与超温保护、系统工具全集、系统监控与磁盘空间、快捷工具、日志导出、代理全链路生效。

UI：全套紫色工具箱图标（exe 资源、托盘、各尺寸 PNG）、AppMark 品牌图形、侧栏与工作台色标、深浅主题、权限提示条。

修复：压测缺超温保护、开机时间单位错误、代理配置不生效、搜索范围过窄、依赖关系从未触发、非空目录误报成功、CPU 首次采样假报 100%、单元素 JSON 退化。

已知限制：部分硬件字段依赖 WMI 提供方；GPU 烤机与传感器取决于驱动与主板；系统级功能需管理员权限；加密备份密码丢失不可恢复；便携版不跨机保存配置。
